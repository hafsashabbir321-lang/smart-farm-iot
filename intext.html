About This Prototype

This prototype demonstrates an IoT-based smart farming monitoring system.

Sensor readings are simulated using JavaScript because physical IoT hardware is not being used during this development stage.

The system monitors environmental conditions and provides alerts when readings become unsuitable for crop growth.
